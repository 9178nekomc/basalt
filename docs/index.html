JSL 2.4.0 文档

欢迎！这里是 JSL 2.4.0 的官方文档。JSL 是一个 Java 调度、Rust 托管底层的 机器学习运行时，覆盖 eager 张量、自动求导、原生 CNN/Transformer 算子与 scikit-learn 风格的经典估计器。

安装

<dependency>
    <groupId>io.github.jsl</groupId>
    <artifactId>jsl-runtime</artifactId>
    <version>2.4.0</version>
</dependency>

运行期需要开启 Vector API 孵化模块：--add-modules jdk.incubator.vector。 原生库已随 jsl-runtime-2.4.0-all.jar 打包；加载失败时经典模型自动回退纯 Java 路径。

快速开始

try (JSL jsl = JSL.create()) {
    Tensor x = jsl.randn(32, 8);
    Tensor y = jsl.randn(32, 1);
    Linear hidden = jsl.linear(8, 16);
    Linear output = jsl.linear(16, 1);
    Tensor loss = output.forward(hidden.forward(x).relu()).mse(y);
    loss.backward();
}

三层 API 边界

层级入口适用场景
整体JSL 门面、Estimator.fit/predict 一行完成训练、预测、交叉验证
模块RandomForest.builder()、HistogramGradientBoosting.builder() 按模块调参、替换求解器、控制线程
原子NativeContext + CommandQueueBuilder 手写算子序列、自定义损失与优化器

模块索引

模块公开类型职责
jsl2统一门面：一次创建上下文，取张量、模块、优化器，并转发经典模型入口。
jsl.core15基础数据层：行主序矩阵、布局标记、原生经典核、模型容器读写原语。
jsl.data6JSLD 数据管线：流式与内存映射两条读取路径、标准化参数。
jsl.io1模型持久化：.jsl v2 容器（magic + kind + 长度 + CRC32C）。
jsl.ml43经典机器学习：线性模型、近邻、SVM、树、梯度提升、聚类、降维、朴素贝叶斯、指标与切分。
jsl.nn36手写神经网络层：Dense / Conv2D / RNN / LSTM / GRU / 注意力、序列训练与序列化。
jsl.nativebridge8原生桥接专家层：上下文、张量句柄、128 字节指令队列、自动求导入口。
jsl.torch24PyTorch 风格 eager API：动态张量、Module 组合、原生 autograd、优化器与损失。
jsl.concurrent1批量推理编排：虚拟线程 + 信号量限流。

文档约定

  • 签名：由 tools/api_dump.py 扫描源码生成，与编译产物一一对应； → 之后是返回类型。

  • 参数：逐个列出名称、类型与语义。标注"默认值"的，取自字段初始值而非推测。

  • 抛出：只列出源码中真实存在的 throw 或显式校验分支。

  • 包内可见类型：没有 public 修饰符但出现在公开签名中的类型， 归入各模块页末尾，不作为稳定 API 承诺。

  • 精度分层：原生张量引擎为 f32，经典估计器保持 f64。

  • 规模：136 个公开类型、826 个公开成员， 其中 826 个成员附有逐参数说明。
