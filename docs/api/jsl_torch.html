final class Activation<L extends Layout> extends Module<L, L>¶

逐元素激活函数模块，保持输入布局

forward 按 kind 分派到 Tensor 上的一元算子：RELU、GELU、SILU、SIGMOID、TANH 直接转调同名方法，LEAKY_RELU 与 ELU 额外把 alpha 传给对应算子。输出与输入同形状，不做任何维度变换，也不改变布局标签。

模块不持有参数，parameters() 恒返回空列表，因此不会进入优化器的参数集；类型参数 L 的作用是让激活在 Sequential 中保持前后布局一致。

注意

kind 不做 null 校验，构造时传入 null 会在 forward 的 switch 分派处抛 NullPointerException。

注意

激活由原生内核逐元素计算，输出是新分配的张量，梯度按元素导数回传。

参见：jsl.torch.Module, jsl.torch.Sequential, jsl.torch.Activation.Kind

final class AdamW extends Optimizer¶

解耦权重衰减与偏差校正的 Adam 优化器

每步执行 p -= lr * (m̂ / (√v̂ + ε) + wd * p)：m̂、v̂ 是经偏差校正的一阶与二阶矩估计，权重衰减以加性项直接作用于参数，不进入矩估计，因此衰减强度与自适应步长相互独立。

一阶、二阶矩缓冲由原生上下文按张量地址保存，首次 step() 时按参数长度惰性分配；参数长度变化会重置缓冲。单参构造器采用 beta1=0.9、beta2=0.999、epsilon=1e-8、weightDecay=0.01。

注意

step() 先自增内部计数器再更新参数，计数器从 1 开始，正好是偏差校正所需的幂次；stepCount() 返回该计数。

注意

构造器不校验 beta1、beta2、epsilon、weightDecay 的取值，传入非有限值会直接污染参数。

注意

同一参数不应同时交给两个优化器：矩缓冲按张量地址存放在上下文中，后创建者会覆盖前者。

参见：jsl.torch.Optimizer, jsl.torch.SGD, jsl.torch.Tensor#adam(float, float, float, float, float, long)

final class BCEWithLogitsLoss implements Loss¶

数值稳定的带 logits 二分类交叉熵

loss(prediction, target) 直接转调 Tensor.bceWithLogitsLoss：prediction 是未过 sigmoid 的 logits，target 与 prediction 形状完全相同、元素取 0 或 1，返回形状 [1] 的标量，按元素总数取平均。

前向用 max(x, 0) - x·y + log1p(exp(-|x|)) 的等价形式逐元素累加，避免 exp 在正半轴溢出；反向不沿 sigmoid 的自动微分链回传，而是把 (sigmoid(x) - y)/n 作为常量系数构造一次 reshape 与 matMul，再叠加常数偏移凑出标量值，因此对 prediction 的一阶梯度精确。

示例
try (JSL jsl = JSL.create()) {
    BCEWithLogitsLoss criterion = new BCEWithLogitsLoss();
    Tensor logits = jsl.randn(4, 1);
    Tensor target = jsl.zeros(4, 1);   // 二分类标签，元素取 0 或 1
    Tensor loss = criterion.loss(logits, target);
    loss.backward();
}

注意

prediction 与 target 形状必须逐维相同，否则抛 IllegalArgumentException；不广播。

注意

target 只被读取原始数值，不参与求导，把它设为 requiresGrad 也不会得到梯度。

注意

返回张量在 prediction 上是线性的替代图，一阶梯度正确，但二阶导数不等于真实 BCE 的 Hessian。

注意

无状态、无可训练参数，可复用同一实例。

参见：jsl.torch.Loss, jsl.torch.CrossEntropyLoss, jsl.torch.Tensor#bceWithLogitsLoss(Tensor)

方法

loss(Tensor prediction, Tensor target) → Tensor¶

计算带 logits 的二分类交叉熵

注意

梯度按 (sigmoid(prediction) - target) / n 附着在 prediction 上，n 为元素总数而非批大小。

参数

  • prediction (Tensor) – 任意形状的 logits 张量，与 target 逐维同形；内部会取 sigmoid，不要预先激活

  • target (Tensor) – 与 prediction 同形状的标签张量，元素取 0 或 1；仅读取数值，不参与求导

返回

形状 [1] 的标量损失张量，值为全体元素的平均，可继续调用 backward()

抛出

  • IllegalArgumentException – prediction 与 target 形状不一致

final class BatchNorm2d extends Module<BCHW, BCHW>¶

NCHW 上的批归一化，含滑动统计量

训练模式下按通道统计 N×H×W 上的均值与方差，用批内方差归一化后做仿射变换，同时按 running = (1 - momentum)·running + momentum·batch 的方向更新滑动均值与滑动方差，即 momentum 是新批统计量的权重。

推理模式不再统计批内数据，直接用滑动均值与滑动方差归一化。写入滑动方差的是无偏估计（spatial 大于 1 时乘 spatial / (spatial - 1)），而归一化本身使用有偏方差。

gamma 初始化为 1、beta 初始化为 0，两者是可训练参数；running_mean 初始化为 0、running_var 初始化为 1，它们是不可训练状态，仅在训练前向中被原地改写。

注意

默认 epsilon 为 1e-5、momentum 为 0.1，来自单参构造器；构造器不校验这两个值的范围。

注意

滑动统计量是模块状态而非参数：parameters() 只返回 gamma 与 beta，namedParameters() 额外给出 running_mean 与 running_var。

注意

在从未训练过的模块上直接 eval()，归一化使用均值 0、方差 1，输出近似为 gamma·x + beta。

参见：jsl.torch.LayerNorm, jsl.torch.Module#train(), jsl.torch.Tensor#batchNorm2d

final class Checkpoint¶

训练检查点的保存与恢复

save 把模块的 stateDict、epoch、loss、优化器学习率与 AdamW 步数写进单个二进制文件：魔数 0x4A534C4B（“JSLK”）、版本 1，随后是 epoch、loss、学习率、步数，再逐项写入名称长度 + UTF-8 名称 + 元素个数 + 以 double 存储的数值。

restore 先 load 再把参数表灌回模块：文件中学习率大于 0 时写回优化器，优化器是 AdamW 时同时恢复步数计数器，返回的 Checkpoint 提供 epoch 与 loss，供续训时对齐轮次与日志。

AdamW 的一阶、二阶矩缓冲保存在原生上下文里、按张量句柄索引，不进入检查点；恢复后矩缓冲从零开始累积，偏差校正按恢复出的步数计算，因此续训初期的更新幅度与不间断训练并不相同。

示例
try (JSL jsl = JSL.create()) {
    Linear model = new Linear(jsl.context(), 16, 4);
    AdamW optimizer = new AdamW(model.parameters(), 1e-3f);
    // ... 训练若干轮
    Checkpoint.save(Path.of("ckpt.bin"), model, optimizer, 3, 0.42f);
    Checkpoint ckpt = Checkpoint.restore(Path.of("ckpt.bin"), model, optimizer);
    int nextEpoch = ckpt.epoch() + 1;
}

注意

参数以 float 写盘、以 double 读回再截断为 float，往返无损；文件不含校验和，也不含模型结构。

注意

save 的 optimizer 允许为 null，此时学习率记 0、步数记 0，restore 侧因此不会覆盖优化器学习率。

注意

load 校验魔数与版本，读完后检查没有剩余字节，任一不符抛 ModelFormatException。

注意

恢复要求模块的 namedParameters 键集与文件一致，缺键抛 IllegalArgumentException；多余键被忽略。

参见：jsl.torch.Module#stateDict(), jsl.torch.AdamW#stepCount(), jsl.torch.CosineAnnealingLR

final class ComputationGraph extends Module<Layout, Layout>¶

支持分支与残差连接的有向无环计算图

图由命名节点组成：输入节点用 addInputs 声明，MODULE 节点引用一个模块并只取单输入，ADD、SUB、MUL 节点只做张量运算、不持有参数。build 时按输入名与已登记节点名统计入度做 Kahn 拓扑排序，得到 executionOrder；排序覆盖不了全部节点就说明存在环，或存在无法从输入到达的节点，抛 IllegalArgumentException。

forward 按 executionOrder 逐节点求值，把输出存进以节点名为键的激活表：MODULE 取 inputs 的第一个名字调用 module.forward，ADD 与 MUL 从第二个输入起逐个累加或累乘，SUB 只接受两个输入做左减右。残差连接就是把同一个上游名字同时登记为模块节点的输入和 ADD 节点的一个输入，两条分支在 ADD 处合流。

多输入用 forwardMany(Tensor...) 或 forward(Map<String, Tensor>) 喂入，多输出分别以按 outputNames 顺序排列的数组和 LinkedHashMap 取回；单输入单输出的图可直接用 forward(Tensor)。求值全部基于普通张量算子，反向传播、train()/eval() 传播与 stateDict 存取都沿用模块体系。

示例
try (JSL jsl = JSL.create()) {
    ComputationGraph graph = ComputationGraph.builder()
            .addInputs("x")
            .addLayer("conv", new Conv2d(jsl.context(), 3, 8, 3, 3, 1, 1, 1, 1, true, 0L), "x")
            .addLayer("block", new Conv2d(jsl.context(), 8, 8, 3, 3, 1, 1, 1, 1, true, 0L), "conv")
            .addAddVertex("res", "conv", "block")   // 残差：把 conv 的输出与 block 的输出相加
            .setOutputs("res")
            .build();
    Tensor y = graph.forward(jsl.randn(2, 3, 16, 16));
    graph.close();
}

注意

ADD 与 MUL 至少需要两个输入，SUB 固定两个；名字与输入名或已有节点重名时在构造阶段抛 IllegalArgumentException。

注意

parameters() 按执行顺序拼接各模块的参数，ADD/SUB/MUL 节点不贡献参数；namedParameters 的键为“节点名.参数名”，因此 stateDict/loadStateDict 可直接用于整图存取。

注意

train()/eval() 与 close() 会传播到所有持有模块的节点；图本身不分配张量，中间结果由各算子按需创建。

注意

执行顺序在 build 时确定且不可变；vertices() 保持登记顺序，与 executionOrder() 的顺序不一定相同。

参见：jsl.torch.Module, jsl.torch.Sequential, jsl.torch.ComputationGraph.Builder

final class Conv2d extends Module<BCHW, BCHW>¶

NCHW 上的二维卷积，支持分组、深度与膨胀

权重形状为 [outputChannels, inputChannels/groups, kernelHeight, kernelWidth]，即按分组切分输入通道的 OIHW；按 Glorot 均匀分布初始化，范围 ±sqrt(6 / (fanIn + fanOut))，其中 fanIn = (inputChannels/groups)·kH·kW、fanOut = (outputChannels/groups)·kH·kW，实际种子为 seed + 31·inputChannels + outputChannels。

偏置形状为 [1, outputChannels, 1, 1]，初始化为 0，在卷积结果上按通道广播相加；useBias 为 false 时不创建偏置，parameters() 与 namedParameters() 相应少一项。

输出空间尺寸为 (H + 2·paddingHeight − (dilationHeight·(kernelHeight − 1) + 1)) / strideHeight + 1，宽度同理，除法向下取整，结果任一维非正时拒绝执行。groups 只改变通道的分组方式，不改变尺寸公式；dilation 通过放大有效核尺寸参与计算，因此同样缩小输出。groups 等于 inputChannels 时为深度卷积，等于 1 时为普通卷积，介于两者之间为分组卷积。

示例
try (JSL jsl = JSL.create()) {
    Conv2d conv = new Conv2d(jsl.context(), 3, 16, 3, 3, 1, 1, 1, 1, true, 42L);
    Tensor input = jsl.randn(4, 3, 32, 32);
    Tensor output = conv.forward(input);
    // output 形状为 [4, 16, 32, 32]
    conv.close();
}

注意

构造器校验通道数、卷积核尺寸、步长、膨胀与 groups 均为正，且 inputChannels、outputChannels 能被 groups 整除；padding 不做校验，传入负值会缩小输出甚至导致输出尺寸非正。

注意

输入通道数必须能被 groups 整除，且 inputChannels/groups 必须等于权重的第二维，否则 Tensor.conv2d 抛 IllegalArgumentException。

注意

偏置通过广播相加实现，会额外产生一个计算图节点；不需要偏置时置 useBias=false 可省去该节点。

参见：jsl.torch.MaxPool2d, jsl.torch.Flatten, jsl.torch.Tensor#conv2d

final class CosineAnnealingLR implements LRScheduler¶

余弦退火学习率调度器

按 lr_t = etaMin + 0.5·(baseLr − etaMin)·(1 + cos(π·t/T_max)) 调整优化器学习率，与 torch.optim.lr_scheduler.CosineAnnealingLR 一致；baseLr 在构造时从 optimizer.learningRate() 读取一次，之后不再跟随外部改动。

step() 先把内部计数器加一，再以 min(t, T_max) 代入公式，把结果写回优化器并返回；t 达到 T_max 后学习率停在 etaMin，继续调用只推进计数器、不再改变取值。

实现不含热重启：没有周期重置，也没有 restart 入口。需要周期性回升时，按周期新建调度器，或在重置点先 setLearningRate 回到 baseLr 再重新计时。

示例
try (JSL jsl = JSL.create()) {
    Linear model = new Linear(jsl.context(), 16, 4);
    AdamW optimizer = new AdamW(model.parameters(), 1e-3f);
    CosineAnnealingLR scheduler = new CosineAnnealingLR(optimizer, 100, 1e-5f);
    for (int epoch = 1; epoch <= 100; epoch++) {
        // ... 前向、反向
        optimizer.step();
        float lr = scheduler.step();
    }
}

注意

tMax 必须为正，etaMin 必须有限且非负，否则构造器抛 IllegalArgumentException；optimizer 为 null 抛 NullPointerException。

注意

currentLearningRate() 返回优化器当前的学习率，而不是按公式重算的值；外部改过优化器学习率后两者会不一致。

注意

计数器从 0 开始，第一次 step() 后 t = 1，因此要经过 T_max 次调用才降到 etaMin。

参见：jsl.torch.LRScheduler, jsl.torch.StepLR, jsl.torch.Optimizer#setLearningRate(float)

final class DepthwiseSeparableConv2d extends Module<BCHW, BCHW>¶

深度可分离二维卷积，先逐通道再 1×1 混合

内部由两个 Conv2d 组成：depthwise 以 groups = inputChannels 做逐通道空间卷积，权重形状 [inputChannels, 1, kernelHeight, kernelWidth]，不设偏置；pointwise 是 1×1、步长 1、无填充的普通卷积，权重形状 [outputChannels, inputChannels, 1, 1]，是否带偏置由 useBias 决定。

forward 串联两段：先按 depthwise 的核、步长、填充、膨胀算出空间尺寸 Hout = (H + 2·pH − (dH·(kH − 1) + 1)) / sH + 1（向下取整），pointwise 不改变空间尺寸，最终输出 [N, outputChannels, Hout, Wout]。

参数按 depthwise 在前、pointwise 在后的顺序拼接；namedParameters 的键带 depthwise. 与 pointwise. 前缀，stateDict 因此能区分两段权重。

示例

    DepthwiseSeparableConv2d block =
            new DepthwiseSeparableConv2d(jsl.context(), 32, 64, 3, 2, 1, 42L);
    Tensor y = block.forward(jsl.randn(1, 32, 56, 56));
    // y 形状为 [1, 64, 28, 28]
    block.close();
}

注意

两段的种子分别是 seed + 17 与 seed + 53，再各自混入通道数，同一个 seed 也能得到不同的初值。

注意

参数校验完全交给两个 Conv2d：通道数、核尺寸、步长、膨胀非正时抛 IllegalArgumentException；inputChannels 与 outputChannels 无需相等。

注意

train()/eval() 与 close() 同时作用于两段；模块自身不持有额外张量。

注意

计算量约为普通 k×k 卷积的 1/outputChannels 加 1/(k×k)，代价是通道间信息只在 pointwise 段交换。

参见：jsl.torch.Conv2d, jsl.torch.BatchNorm2d, jsl.torch.Activation

final class Dropout<L extends Layout> extends Module<L, L>¶

倒置 dropout，推理期为恒等映射

训练模式下按概率 probability 把元素置零，并把保留的元素乘以 1 / (1 - probability)，使前向期望保持不变；probability 为 0 时直接返回输入的副本。

推理模式或 probability 为 0 时掩码全为 1，输出等于输入，因此同一模块可以在训练与推理之间反复切换而不改变调用方式。

掩码由原生内核用 xorshift64 从 seed 生成，给定种子完全确定；模块在每次 forward 之后把内部 seed 加一，所以连续调用得到不同掩码，而整条序列可复现。

注意

构造器校验 probability 落在 [0, 1)，越界抛 IllegalArgumentException；单参构造器的默认种子为 0x9E3779B97F4A7C15。

注意

掩码按元素个数生成，与形状无关；同一次前向与对应反向使用同一掩码。

注意

内部 seed 可变，同一实例不宜跨线程并发调用 forward。

参见：jsl.torch.Module#train(), jsl.torch.Tensor#dropout

final class GroupNorm<L extends Layout> extends Module<L, L>¶

按通道分组归一化，结果与批量大小无关

构造时按 numChannels 分配两个一维可训练张量 gamma 与 beta，形状均为 [numChannels]，分别填充 1 与 0；默认 epsilon 为 1e-5f。类本身只保存配置，不持有滑动统计量。

forward 转调 Tensor.groupNorm：把第二维的 C 个通道均分为 numGroups 组，每组包含 numChannels / numGroups 个通道及其全部空间位置；在该组内计算均值与方差，除以组内元素数，归一化后按通道应用 gamma、beta。

其余维度按行主序合并为空间维，统计既不跨样本也不跨分组；输出与输入同形状，因此可以直接接在 Conv2d 之后。与 BatchNorm2d 不同，训练与推理行为完全一致。

注意

interface LRScheduler¶

学习率调度器的统一契约

实现类在内部维护步数计数：step() 推进一步并算出新学习率，通过 Optimizer.setLearningRate 写回优化器，同时返回该值；currentLearningRate() 与 currentStep() 提供只读查询。三个方法都不带参数。

注意

step() 直接改写优化器学习率，与是否调用过 optimizer.step() 无关。

注意

写回的学习率必须有限且非负，否则 Optimizer.setLearningRate 抛 IllegalArgumentException。

注意

实现类在构造时绑定单个 Optimizer，同一实例不应跨优化器复用。

注意

接口不声明异常，也不规定步数上限；计数只增不减，没有重置入口。

参见：jsl.torch.StepLR, jsl.torch.CosineAnnealingLR, jsl.torch.Optimizer#setLearningRate(float)

final class MultiheadAttention extends Module<BSF, BSF>¶

多头自注意力，输入 [batch, time, channels]

构造时创建 query、key、value、output 四个 dimension 到 dimension 的 Linear，均带偏置，并创建作用于注意力权重的 Dropout；缩放系数是值为 1/sqrt(dimension / heads) 的标量张量。

forward 先把每个投影结果 reshape 成 [B, T, H, dh]：Q 与 V 经 permute(0, 2, 1, 3) 变为 [B·H, T, dh]，K 经 permute(0, 2, 3, 1) 变为 [B·H, dh, T]，再做批量矩阵乘得到 [B·H, T, T] 的分数。

分数乘缩放系数，causal 为真时把 column > row 的位置加上 -1e9，随后沿最后一维 softmax、过 dropout，再与 V 相乘得 [B·H, T, dh]，reshape 成 [B, H, T, dh] 并 permute(0, 2, 1, 3) 还原为 [B, T, C]，最后经输出投影。

            new MultiheadAttention(jsl.context(), 64, 8, true, 0.1f, 7L);
    Tensor input = jsl.randn(2, 16, 64);
    attention.train();
    Tensor output = attention.forward(input);

abstract class Optimizer¶

final class Sequential<I extends Layout, O extends Layout> extends Module<I, O>¶

类型态模块流水线：add 返回新实例并推进布局类型

start() 产生空的 Sequential<L, L>，L 由目标类型或上下文推断；add 要求实参是 Module<O, N>，返回 Sequential<I, N>，于是链条上每一步都把上一层输出布局钉成下一层输入布局。

因此 Conv2d（BCHW→BCHW）之后直接接 Linear（BC→BC）无法通过编译，必须插入 Flatten（BCHW→BC）把布局改写成 BC 才能继续。

实例不可变：add 复制模块列表并返回新对象，原对象保持为空，只有最终对象代表完整流水线。forward 按插入顺序依次调用，parameters 与 namedParameters 按同样顺序拼接。

示例
import jsl.JSL;
import jsl.core.BC;
import jsl.nn.Activation;
import jsl.torch.AdamW;
import jsl.torch.Loss;
import jsl.torch.Optimizer;
import jsl.torch.Sequential;
import jsl.torch.Tensor;

try (JSL jsl = JSL.create()) {
    // start() 产生空流水线，输入与输出都钉在 BC
    Sequential<BC, BC> model = Sequential.<BC>start()
            .add(jsl.linear(8, 16))
            .add(jsl.activation(Activation.RELU))
            .add(jsl.linear(16, 4));

    Tensor features = jsl.randn(32, 8);
    Tensor targets = jsl.zeros(32, 4);
    Loss criterion = jsl.mse();
    Optimizer optimizer = new AdamW(model.parameters(), 0.01f);

    for (int step = 0; step < 5; step++) {
        Tensor loss = criterion.loss(model.forward(features), targets);
        loss.backward();       // 1. 反向：梯度累积到参数
        optimizer.step();      // 2. 更新：消费当前梯度
        optimizer.zeroGrad();  // 3. 清零：为下一批准备
        jsl.clearGraph();      // 4. 清图：丢弃本步节点与中间张量
    }
}

注意

空流水线的 forward 直接返回输入引用，不做复制。

注意

namedParameters 的键带 layer{i}. 前缀并与子模块自身的键拼接，可直接用于 stateDict。

注意

train()/eval() 递归传播到子模块，但 isTraining() 只反映 Sequential 自身的标志。

注意

close() 递归关闭子模块；同一模块实例加入多条流水线时，关闭其中一条会释放共享参数。

注意

depth() 返回直接子模块个数，不是嵌套深度。

参见：jsl.torch.Module, jsl.torch.Linear, jsl.torch.Conv2d, jsl.torch.Flatten

方法

final class SmoothL1Loss implements Loss¶

带 beta 转折点的 Smooth L1（Huber）损失

前向对每个元素按 d = prediction − target 与 beta 的关系分段：|d| < beta 取 d²/(2β)，否则取 |d| − β/2；最后对所有元素取算术平均，返回形状 [1] 的标量张量。

实现全由公开算子组合：差值乘上逐元素构造的系数与偏移张量，再与 1/n 的全 1 向量做矩阵乘求均值，因此反向梯度与解析式一致（内侧 d/β，外侧 sign(d)/n）。

beta ≤ 0 时直接退化为 l1Loss，即平均绝对误差。

注意

默认构造器取 beta = 1.0，与 torch.nn.SmoothL1Loss 的默认分段一致。

注意

构造器只拒绝负 beta，不校验有限性；NaN 会一路传播到输出。

注意

prediction 与 target 必须逐维相等，否则抛 IllegalArgumentException。

注意

均值除以元素总数而非 batch 大小；分段掩码在 Java 侧逐元素生成，每次前向多一次 data() 全量拷贝。

参见：jsl.torch.Tensor#smoothL1Loss(Tensor, float), jsl.torch.L1Loss, jsl.torch.MSELoss

final class StepLR implements LRScheduler¶

每隔 stepSize 步按 gamma 衰减学习率的调度器

构造时把优化器当前学习率定格为基准 baseLr，并保存 stepSize 与 gamma；每次 step() 先把内部计数器加一，再用整数除法 decays = currentStep / stepSize 求衰减次数，写回 baseLr · gamma^decays。

于是从 0 开始的前 stepSize−1 次调用学习率保持 baseLr，第 stepSize 次调用恰好衰减一次，之后每再走 stepSize 步再乘一次 gamma；学习率按 baseLr·gamma^k 阶梯下降，不会逐次累乘产生漂移。

调度器只改写优化器的学习率字段，不触碰梯度、动量与计算图，其节奏必须与优化器 step() 的调用对齐。

注意

stepSize ≤ 0 抛 IllegalArgumentException，gamma ≤ 0 或非有限同样抛 IllegalArgumentException，optimizer 为 null 抛 NullPointerException。

注意

gamma 未限制小于 1，大于 1 时学习率阶梯上升。

注意

baseLr 构造时定格：之后手动 setLearningRate 或换用别的调度器都不改变已算好的基准。

注意

计数器是普通 int 且不参与同步，多线程共用同一调度器会重复计数。

注意

与 torch.optim.lr_scheduler.StepLR 对齐：第 e 步的学习率为 baseLr · gamma^(e // stepSize)。

参见：jsl.torch.LRScheduler, jsl.torch.Optimizer#setLearningRate(float), jsl.torch.CosineAnnealingLR

final class Tensor implements AutoCloseable¶

Rust 内核支撑的 eager 张量：即时求值、反向求导与参数句柄

每次算子调用都立即在原生引擎执行并返回新张量，同时在计算图中登记一条节点，因此前向、损失与反向可以按语句顺序逐步执行，无需先构图再运行。用 parameter 创建的张量在 backward() 后累积梯度。

形状在运行期动态决定，与 torch.Tensor 一致；编译期的布局安全由上层的 Module/Sequential 泛型提供。Java 对象只保存不透明句柄与形状副本，数据始终留在原生连续缓冲中。

示例
import jsl.JSL;
import jsl.torch.Tensor;

try (JSL jsl = JSL.create()) {
    Tensor features = jsl.randn(4, 3);          // 形状 [4, 3]，不求导
    Tensor weight = jsl.parameter(3, 1);        // 可训练参数，零初始化
    Tensor loss = features.matMul(weight)       // [4, 3] x [3, 1] -> [4, 1]
            .mse(jsl.zeros(4, 1));              // 标量损失，形状 [1]

    loss.backward();                            // 梯度累加到 weight
    float[] gradient = weight.grad();            // 复制出梯度
    weight.sgd(0.1f, 0.0f);                     // weight -= lr * grad
    weight.zeroGrad();                          // 清梯度
    jsl.clearGraph();                           // 清图，避免节点累积
}

注意

算子只登记到所属上下文的当前计算图：同一上下文内连续训练需在每步末清图，否则节点与中间张量持续累积。

注意

关闭任何被计算图引用的张量会清空整张图，因此中间张量不要在 backward() 之前 close()。

注意

backward() 既不自动清图也不清零梯度；梯度按累加写入，重复调用会叠加。

注意

算子输出张量的 requiresGrad 为 false，但仍作为图节点参与反向，梯度只累加到 requiresGrad 为 true 的张量上。

注意

data()/grad() 每次都把原生缓冲复制成新 float[]，热路径上频繁调用会产生额外拷贝与 GC 压力。

注意

张量绑定创建它的 NativeContext，跨上下文混用会在队列执行时被拒绝；单个张量的元素总数上限为 Integer.MAX_VALUE。

参见：jsl.torch.Module, jsl.torch.Graph, jsl.torch.Optimizer, jsl.nativebridge.NativeContext

groupNorm(Tensor gamma, Tensor beta, int groups, float epsilon) → Tensor¶

按通道分组做归一化

把 C 个通道分成 groups 组，每组将 channels_per_group × spatial 个元素拉平后求均值与有偏方差，以 sqrt(var + epsilon) 为分母归一化，再逐通道乘 gamma、加 beta。统计在每个样本的每个分组内独立计算，不维护运行统计。

注意

注意

注意

注意

返回

与输入同形状的新张量

抛出

  • IllegalArgumentException – 输入秩小于 2、C 不能被 groups 整除，或 gamma/beta 元素数不等于 C

  • ArithmeticException – groups 为 0

l1Loss(Tensor target) → Tensor¶

smoothL1Loss(Tensor target, float beta) → Tensor¶

先校验形状相等；beta ≤ 0 时转调 l1Loss。beta > 0 时对每个元素取 d = 本张量 − target：|d| < beta 记 d²/(2β)，否则记 |d| − β/2，最后对全部元素取平均。

参数

  • target (Tensor) – 目标张量，须与本张量逐维相等

抛出

  • IllegalArgumentException – 两侧形状不完全相同（消息为 SmoothL1Loss expects equal shapes）

static final class ComputationGraph.Builder¶

按名字登记节点、在 build 时排序并校验的计算图构造器

所有登记方法都返回 this，因此可以链式声明整张图。输入名与顶点名共用同一张命名空间表：addInputs 检查名字是否已作为输入或顶点存在，checkUnique 检查顶点名是否与已有输入或顶点冲突。节点登记不校验输入引用是否已声明，引用可以指向稍后才登记的节点，甚至形成环，这些检查全部推迟到 build。

build 先确认至少有一个输入和一个输出，再要求每个输出名指向输入或已登记顶点；接着按顶点输入个数建立入度表，从输入节点出发做 Kahn 拓扑排序得到执行顺序。排序结束后仍有顶点未出队，说明定义含环或存在从输入不可达的节点，两者都抛 IllegalArgumentException。构造过程不分配张量，也不执行任何计算。

示例
ComputationGraph graph = ComputationGraph.builder()
        .addInputs("x", "skip")
        .addAddVertex("res", "x", "skip")
        .addSubVertex("diff", "x", "skip")
        .setOutputs("res", "diff")
        .build();

注意

模块按引用登记，图与调用方共享同一个模块实例；ComputationGraph.close() 会关闭这些模块。

注意

顶点名与输入名不得重复，重复项在登记阶段即抛异常，不会留到 build。

注意

ADD 与 MUL 至少两个输入，SUB 固定两个；单输入模块节点用 addLayer 登记。

注意

同一个 Builder 可反复 build，每次得到独立实例，执行顺序在各自构建时确定。

参见：jsl.torch.ComputationGraph, jsl.torch.ComputationGraph.Vertex, jsl.torch.Module

方法

addInputs(String... names) → Builder¶

声明图输入节点，按声明顺序确定位置参数

逐个登记名字，并在写入前检查冲突，因此同一批参数内部的重复也会被发现。输入名同时决定 forwardMany 的位置顺序，也是 forward(Map) 的必需键。

参数

  • names (String...) – 输入节点名，不得与已有输入或顶点重名

返回

this，便于链式调用

抛出

  • IllegalArgumentException – 某个名字已作为输入或顶点登记

  • NullPointerException – 任一名字为 null

addLayer(String name, Module<?, ?> module, String input) → Builder¶

登记引用模块的单输入节点

算子固定为 MODULE，顶点只保存模块引用，不复制实例；前向时取唯一输入调用 module.forward。模块参数按执行顺序进入整图的 parameters()，命名参数以“节点名.参数名”为键。

参数

  • name (String) – 节点名，须在输入与顶点中唯一

  • module (Module<?, ?>) – 被引用的模块，负责该节点的前向计算与参数

  • input (String) – 上游节点或输入的名字，不要求已声明

返回

this，便于链式调用

抛出

  • IllegalArgumentException – name 与已有输入或顶点重名

  • NullPointerException – name、module 或 input 为 null

addAddVertex(String name, String... inputs) → Builder¶

登记逐元素相加节点，至少两个输入

算子为 ADD，不持有模块；前向时从第一个输入开始依次调用 add，因此参与相加的张量形状须能两两广播。残差连接就是把模块链的输入与输出同时登记为这里的两个输入。

参数

  • name (String) – 节点名，须在输入与顶点中唯一

  • inputs (String...) – 上游名字，至少两个，按传入顺序左结合相加

返回

this，便于链式调用

抛出

  • IllegalArgumentException – inputs 为 null 或少于两个，或 name 与已有输入、顶点重名

  • NullPointerException – inputs 中存在 null 元素

addSubVertex(String name, String leftInput, String rightInput) → Builder¶

登记左减右的二元减法节点

算子为 SUB，前向时计算 leftInput - rightInput，两侧形状须可广播。签名已限定两个输入，因此不再做输入个数检查。

参数

  • name (String) – 节点名，须在输入与顶点中唯一

  • leftInput (String) – 被减数的上游名字

  • rightInput (String) – 减数的上游名字

返回

this，便于链式调用

抛出

  • IllegalArgumentException – name 与已有输入或顶点重名

  • NullPointerException – leftInput 或 rightInput 为 null

addMulVertex(String name, String... inputs) → Builder¶

登记逐元素相乘节点，至少两个输入

算子为 MUL，前向时从第一个输入开始依次调用 mul。常见用法是门控：把同一个上游名字分别作为门控信号与被门控特征传入，得到逐元素乘积。

参数

  • name (String) – 节点名，须在输入与顶点中唯一

  • inputs (String...) – 上游名字，至少两个，按传入顺序左结合相乘

返回

this，便于链式调用

抛出

  • IllegalArgumentException – inputs 为 null 或少于两个，或 name 与已有输入、顶点重名

  • NullPointerException – inputs 中存在 null 元素

setOutputs(String... names) → Builder¶

声明图输出节点，覆盖此前设置

先清空已有输出再逐个登记，重复调用以最后一次为准。输出名的存在性不在本方法校验，而是留到 build 时与输入名、顶点名一起比对。

注意

同名重复声明不会被去重，取回结果时按名字查表，因此得到的是同一个张量。

参数

  • names (String...) – 输出名，须指向输入或已登记顶点

返回

this，便于链式调用

抛出

  • NullPointerException – 任一名字为 null

build() → ComputationGraph¶

校验图定义并返回拓扑序固定的计算图

入度按每个顶点的输入个数初始化，再从输入节点出发逐个扣减消费方的入度，减到 0 即入队，出队顺序写入 executionOrder。校验与排序都只读构造器状态，因此构建成功后仍可继续登记节点，已建好的图不受影响。

返回

按拓扑序保存执行顺序的 ComputationGraph

抛出

  • IllegalArgumentException – 没有输入或没有输出、输出名未知、顶点引用未知输入，或定义中存在环与不可达顶点

record ComputationGraph.Vertex¶

计算图节点的不可变描述：名字、算子、模块与输入名

四个分量在登记时确定：name 是节点标识，op 决定前向运算，module 只在 MODULE 节点上非 null，inputs 是上游名字的列表。op 为 MODULE 时 inputs 只有一个元素，ADD、SUB、MUL 节点的 module 为 null，只做张量运算。

inputs 由 List.of 生成，是不可变列表；record 的访问器直接返回该引用而不复制。节点按登记顺序存放在 Builder 的 LinkedHashMap 中，构图后经 vertices() 以只读映射暴露，遍历顺序与登记顺序一致，与 executionOrder() 的拓扑序不一定相同。

注意

record 只提供访问器，没有额外校验或归一化；取值前应先按 op 判断 module 是否可用。

注意

参数集合不包含在此记录中，参数由 module.parameters() 提供。

参见：jsl.torch.ComputationGraph, jsl.torch.ComputationGraph.VertexOp

enum ComputationGraph.VertexOp¶

节点算子类型：模块调用、相加、相减、相乘

MODULE 表示节点引用一个模块并对唯一输入调用 forward；ADD 与 MUL 把多个输入逐个累加或累乘，SUB 只接受两个输入计算左减右。前向的 switch 覆盖全部四个常量，没有默认分支。

枚举值同时决定顶点是否携带模块：只有 MODULE 节点的 module 非 null，其余三种节点的运算完全由张量算子完成，因此不贡献参数，也不随 train()、eval() 改变状态。

注意

ADD 与 MUL 的输入个数由 Builder 保证至少两个，枚举本身不携带元数信息。

注意

算子类型在登记后不可变，改变算子需要重新登记节点。

参见：jsl.torch.ComputationGraph.Vertex, jsl.torch.ComputationGraph.Builder
