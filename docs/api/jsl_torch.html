模块 jsl.torch¶

24 个公开类型

jsl.torch 是 JSL 的 eager 执行面：算子调用即执行、即返回新张量，并在原生计算图中登记一条节点，反向传播随后沿这些节点累积梯度。计算本身由 Rust 内核完成，Java 侧只持有不透明句柄与形状副本。

编译期的形状安全由上层的 Module/Sequential 泛型提供：模块用幽灵布局类型参数标注输入输出布局，串接时由类型检查器拒绝不兼容的连接；Tensor 本身与 torch.Tensor 一样是运行期动态形状。

final class Activation<L extends Layout> extends Module<L, L>¶

逐元素激活函数模块，保持输入布局

forward 按 kind 分派到 Tensor 上同名的一元算子：RELU、GELU、SILU、SIGMOID、TANH。输出与输入同形状，不做任何维度变换，也不改变布局标签。

模块不持有参数，parameters() 恒返回空列表，因此不会进入优化器的参数集；类型参数 L 的作用是让激活在 Sequential 中保持前后布局一致。

注意

kind 不做 null 校验，构造时传入 null 会在 forward 的 switch 分派处抛 NullPointerException。

注意

激活由原生内核逐元素计算，输出是新分配的张量，梯度按元素导数回传。

参见：jsl.torch.Module, jsl.torch.Sequential, jsl.torch.Activation.Kind

final class AdamW extends Optimizer¶

解耦权重衰减与偏差校正的 Adam 优化器

每步执行 p -= lr * (m̂ / (√v̂ + ε) + wd * p)：m̂、v̂ 是经偏差校正的一阶与二阶矩估计，权重衰减以加性项直接作用于参数，不进入矩估计，因此衰减强度与自适应步长相互独立。

一阶、二阶矩缓冲由原生上下文按张量地址保存，首次 step() 时按参数长度惰性分配；参数长度变化会重置缓冲。单参构造器采用 beta1=0.9、beta2=0.999、epsilon=1e-8、weightDecay=0.01。

注意

step() 先自增内部计数器再更新参数，计数器从 1 开始，正好是偏差校正所需的幂次；stepCount() 返回该计数。

注意

构造器不校验 beta1、beta2、epsilon、weightDecay 的取值，传入非有限值会直接污染参数。

注意

同一参数不应同时交给两个优化器：矩缓冲按张量地址存放在上下文中，后创建者会覆盖前者。

参见：jsl.torch.Optimizer, jsl.torch.SGD, jsl.torch.Tensor#adam(float, float, float, float, float, long)

final class BatchNorm2d extends Module<BCHW, BCHW>¶

NCHW 上的批归一化，含滑动统计量

训练模式下按通道统计 N×H×W 上的均值与方差，用批内方差归一化后做仿射变换，同时按 running = (1 - momentum)·running + momentum·batch 的方向更新滑动均值与滑动方差，即 momentum 是新批统计量的权重。

推理模式不再统计批内数据，直接用滑动均值与滑动方差归一化。写入滑动方差的是无偏估计（spatial 大于 1 时乘 spatial / (spatial - 1)），而归一化本身使用有偏方差。

gamma 初始化为 1、beta 初始化为 0，两者是可训练参数；running_mean 初始化为 0、running_var 初始化为 1，它们是不可训练状态，仅在训练前向中被原地改写。

注意

默认 epsilon 为 1e-5、momentum 为 0.1，来自单参构造器；构造器不校验这两个值的范围。

注意

滑动统计量是模块状态而非参数：parameters() 只返回 gamma 与 beta，namedParameters() 额外给出 running_mean 与 running_var。

注意

在从未训练过的模块上直接 eval()，归一化使用均值 0、方差 1，输出近似为 gamma·x + beta。

参见：jsl.torch.LayerNorm, jsl.torch.Module#train(), jsl.torch.Tensor#batchNorm2d

final class Conv2d extends Module<BCHW, BCHW>¶

NCHW 上的二维卷积，可选偏置

权重形状为 [outputChannels, inputChannels, kernelHeight, kernelWidth]（OIHW），按 Glorot 均匀分布初始化，范围为 ±sqrt(6 / (fanIn + fanOut))，其中 fanIn = inputChannels·kH·kW、fanOut = outputChannels·kH·kW；实际种子为 seed + 31·inputChannels + outputChannels。

偏置形状为 [1, outputChannels, 1, 1]，初始化为 0，在卷积结果上按通道广播相加；useBias 为 false 时不创建偏置，parameters() 与 namedParameters() 相应少一项。

输出空间尺寸为 (H + 2·paddingHeight − kernelHeight) / strideHeight + 1，除法向下取整，宽度同理；结果任一维非正时拒绝执行。实现只提供单组卷积，没有 groups 与 dilation 参数。

示例
try (JSL jsl = JSL.create()) {
    Conv2d conv = new Conv2d(jsl.context(), 3, 16, 3, 3, 1, 1, 1, 1, true, 42L);
    Tensor input = jsl.randn(4, 3, 32, 32);
    Tensor output = conv.forward(input);
    // output 形状为 [4, 16, 32, 32]
    conv.close();
}

注意

构造器只校验通道数与卷积核尺寸为正，不校验 stride 与 padding；stride 传 0 会在原生内核中除零。

注意

输入通道数必须等于权重的第二维，否则 Tensor.conv2d 抛 IllegalArgumentException。

注意

偏置通过广播相加实现，会额外产生一个计算图节点；不需要偏置时置 useBias=false 可省去该节点。

参见：jsl.torch.MaxPool2d, jsl.torch.Flatten, jsl.torch.Tensor#conv2d

final class CrossEntropyLoss implements Loss¶

融合 softmax 与负对数似然的分类损失

loss(prediction, target) 直接转调 Tensor.crossEntropy：prediction 是 [N, C] 的未归一化 logits，target 是长度 N 的类索引（以 float 存储），返回形状 [1] 的标量，按 N 取平均。

前向用 log-sum-exp 稳定计算，反向一次得到 (softmax - onehot) / N，不需要显式构造 softmax 再取对数，省去中间张量与溢出风险。

注意

target 越界或非有限由原生层拒绝，抛 IllegalStateException；形状不符在 Java 侧抛 IllegalArgumentException。

注意

不支持类别权重、ignore_index 与 label smoothing，类别不平衡需自行加权或重采样。

注意

无状态、无可训练参数，可复用同一实例。

参见：jsl.torch.Loss, jsl.torch.MSELoss, jsl.torch.Tensor#crossEntropy(Tensor)

方法

计算批量平均的交叉熵

  • target (Tensor) – 元素个数为 N 的类索引张量，取值须落在 [0, C)

抛出

final class Dropout<L extends Layout> extends Module<L, L>¶

倒置 dropout，推理期为恒等映射

训练模式下按概率 probability 把元素置零，并把保留的元素乘以 1 / (1 - probability)，使前向期望保持不变；probability 为 0 时直接返回输入的副本。

推理模式或 probability 为 0 时掩码全为 1，输出等于输入，因此同一模块可以在训练与推理之间反复切换而不改变调用方式。

掩码由原生内核用 xorshift64 从 seed 生成，给定种子完全确定；模块在每次 forward 之后把内部 seed 加一，所以连续调用得到不同掩码，而整条序列可复现。

注意

构造器校验 probability 落在 [0, 1)，越界抛 IllegalArgumentException；单参构造器的默认种子为 0x9E3779B97F4A7C15。

注意

掩码按元素个数生成，与形状无关；同一次前向与对应反向使用同一掩码。

注意

内部 seed 可变，同一实例不宜跨线程并发调用 forward。

参见：jsl.torch.Module#train(), jsl.torch.Tensor#dropout

final class Embedding extends Module<BC, BSF>¶

词表查找表，索引以 f32 存整数

权重形状为 [vocabularySize, dimension]，按 ±1/sqrt(dimension) 的均匀分布初始化，实际种子为 seed + 41·vocabularySize + dimension。

forward 把输入中的每个元素当作行号，取出对应的 dimension 维向量，输出形状为输入形状末尾追加一维 dimension；输入可以是任意秩，不限于 [batch, sequence]。

索引以 f32 存储，原生内核校验其有限且落在 [0, vocabularySize) 内，随后截断为整数行号再拷贝整行权重。

注意

索引应为整数值的浮点数；带小数部分时会被截断取整，不报错。

注意

vocabularySize 与 dimension 必须为正，否则张量分配阶段抛 IllegalArgumentException。

注意

反向传播按索引做散射累加，同一索引在输入中出现多次时梯度相加。

参见：jsl.torch.Linear, jsl.torch.Tensor#embedding

final class Linear extends Module<BC, BC>¶

权重形状为 [inputSize, outputSize]，按 ±sqrt(6 / (inputSize + outputSize)) 的均匀分布初始化，实际种子为 seed + 17·inputSize + outputSize；偏置形状为 [1, outputSize]，初始化为 0。

注意

构造器不校验 inputSize、outputSize 的取值，非正尺寸在张量分配阶段抛 IllegalArgumentException。

注意

useBias 为 false 时 bias() 返回 null，parameters() 与 namedParameters() 只含 weight。

注意

形状检查发生在前向，最后一维不匹配时异常信息包含期望值与实际值。

final class MultiheadAttention extends Module<BSF, BSF>¶

多头自注意力，输入 [batch, time, channels]

构造时创建 query、key、value、output 四个 dimension 到 dimension 的 Linear，均带偏置，并创建作用于注意力权重的 Dropout；缩放系数是值为 1/sqrt(dimension / heads) 的标量张量。

forward 先把每个投影结果 reshape 成 [B, T, H, dh]：Q 与 V 经 permute(0, 2, 1, 3) 变为 [B·H, T, dh]，K 经 permute(0, 2, 3, 1) 变为 [B·H, dh, T]，再做批量矩阵乘得到 [B·H, T, T] 的分数。

分数乘缩放系数，causal 为真时把 column > row 的位置加上 -1e9，随后沿最后一维 softmax、过 dropout，再与 V 相乘得 [B·H, T, dh]，reshape 成 [B, H, T, dh] 并 permute(0, 2, 1, 3) 还原为 [B, T, C]，最后经输出投影。

示例
try (JSL jsl = JSL.create()) {
    MultiheadAttention attention =
            new MultiheadAttention(jsl.context(), 64, 8, true, 0.1f, 7L);
    Tensor input = jsl.randn(2, 16, 64);
    attention.train();
    Tensor output = attention.forward(input);
    // output 形状为 [2, 16, 64]
    attention.eval();
    attention.close();
}

注意

dimension 必须能被 heads 整除，否则构造与前向都抛 IllegalArgumentException；heads 本身不做正值校验。

注意

因果掩码只屏蔽未来位置（严格上三角），每次前向都按 time×time 新建一个掩码张量。

注意

train()/eval() 会同步切换内部 dropout；parameters() 只含四个投影的权重与偏置，不含缩放常量。

注意

namedParameters 的名称前缀为 query.、key.、value.、output.。

abstract class Optimizer¶

构造时要求参数列表非空、学习率有限且为正，列表被复制为不可变视图，之后修改原列表不影响优化器。子类只需实现 step()，在其中对每个参数调用张量级的更新原语。

注意

final class Sequential<I extends Layout, O extends Layout> extends Module<I, O>¶

类型态模块流水线：add 返回新实例并推进布局类型

start() 产生空的 Sequential<L, L>，L 由目标类型或上下文推断；add 要求实参是 Module<O, N>，返回 Sequential<I, N>，于是链条上每一步都把上一层输出布局钉成下一层输入布局。

因此 Conv2d（BCHW→BCHW）之后直接接 Linear（BC→BC）无法通过编译，必须插入 Flatten（BCHW→BC）把布局改写成 BC 才能继续。

实例不可变：add 复制模块列表并返回新对象，原对象保持为空，只有最终对象代表完整流水线。forward 按插入顺序依次调用，parameters 与 namedParameters 按同样顺序拼接。

示例
import jsl.JSL;
import jsl.core.BC;
import jsl.nn.Activation;
import jsl.torch.AdamW;
import jsl.torch.Loss;
import jsl.torch.Optimizer;
import jsl.torch.Sequential;
import jsl.torch.Tensor;

try (JSL jsl = JSL.create()) {
    // start() 产生空流水线，输入与输出都钉在 BC
    Sequential<BC, BC> model = Sequential.<BC>start()
            .add(jsl.linear(8, 16))
            .add(jsl.activation(Activation.RELU))
            .add(jsl.linear(16, 4));

    Tensor features = jsl.randn(32, 8);
    Tensor targets = jsl.zeros(32, 4);
    Loss criterion = jsl.mse();
    Optimizer optimizer = new AdamW(model.parameters(), 0.01f);

    for (int step = 0; step < 5; step++) {
        Tensor loss = criterion.loss(model.forward(features), targets);
        loss.backward();       // 1. 反向：梯度累积到参数
        optimizer.step();      // 2. 更新：消费当前梯度
        optimizer.zeroGrad();  // 3. 清零：为下一批准备
        jsl.clearGraph();      // 4. 清图：丢弃本步节点与中间张量
    }
}

注意

注意

注意

train()/eval() 递归传播到子模块，但 isTraining() 只反映 Sequential 自身的标志。

注意

注意

final class Tensor implements AutoCloseable¶

Rust 内核支撑的 eager 张量：即时求值、反向求导与参数句柄

每次算子调用都立即在原生引擎执行并返回新张量，同时在计算图中登记一条节点，因此前向、损失与反向可以按语句顺序逐步执行，无需先构图再运行。用 parameter 创建的张量在 backward() 后累积梯度。

形状在运行期动态决定，与 torch.Tensor 一致；编译期的布局安全由上层的 Module/Sequential 泛型提供。Java 对象只保存不透明句柄与形状副本，数据始终留在原生连续缓冲中。

示例
import jsl.JSL;
import jsl.torch.Tensor;

try (JSL jsl = JSL.create()) {
    Tensor features = jsl.randn(4, 3);          // 形状 [4, 3]，不求导
    Tensor weight = jsl.parameter(3, 1);        // 可训练参数，零初始化
    Tensor loss = features.matMul(weight)       // [4, 3] x [3, 1] -> [4, 1]
            .mse(jsl.zeros(4, 1));              // 标量损失，形状 [1]

    loss.backward();                            // 梯度累加到 weight
    float[] gradient = weight.grad();            // 复制出梯度
    weight.sgd(0.1f, 0.0f);                     // weight -= lr * grad
    weight.zeroGrad();                          // 清梯度
    jsl.clearGraph();                           // 清图，避免节点累积
}

注意

算子只登记到所属上下文的当前计算图：同一上下文内连续训练需在每步末清图，否则节点与中间张量持续累积。

注意

关闭任何被计算图引用的张量会清空整张图，因此中间张量不要在 backward() 之前 close()。

注意

backward() 既不自动清图也不清零梯度；梯度按累加写入，重复调用会叠加。

注意

算子输出张量的 requiresGrad 为 false，但仍作为图节点参与反向，梯度只累加到 requiresGrad 为 true 的张量上。

注意

data()/grad() 每次都把原生缓冲复制成新 float[]，热路径上频繁调用会产生额外拷贝与 GC 压力。

注意

张量绑定创建它的 NativeContext，跨上下文混用会在队列执行时被拒绝；单个张量的元素总数上限为 Integer.MAX_VALUE。

参见：jsl.torch.Module, jsl.torch.Graph, jsl.torch.Optimizer, jsl.nativebridge.NativeContext

final class TransformerBlock extends Module<BSF, BSF>¶

pre-norm 结构的 Transformer 块

前向为 pre-norm 顺序：先对输入做 LayerNorm 再进多头注意力，注意力输出过 dropout 后与输入相加；所得残差再做 LayerNorm、升维 Linear、GELU、降维 Linear，过 dropout 后与残差相加。

两个 LayerNorm 的 epsilon 固定为 1e-5；FFN 隐藏维由 hiddenSize 指定，激活固定为 GELU；注意力输出与 FFN 输出各过一次 dropout，两者共用同一个 Dropout 实例。

注意

dimension 必须能被 heads 整除，否则构造时由 MultiheadAttention 抛 IllegalArgumentException。

注意

共用 dropout 实例意味着两次 dropout 使用相邻但不同的种子，掩码互不相同。

注意

train()/eval() 递归切换 norm1、attention、norm2、两个 Linear 与 dropout；parameters() 不含 dropout 与激活，因为它们没有参数。

注意

namedParameters 的名称前缀为 norm1.、attention.、norm2.、ffn1.、ffn2.。

参见：jsl.torch.MultiheadAttention, jsl.torch.LayerNorm, jsl.torch.Activation

train()¶

递归切换到训练模式

注意

逐个调用 norm1、attention、norm2、两个 Linear 与 dropout 的 train()。

eval()¶

递归切换到推理模式

注意

推理时两处 dropout 均为恒等映射，注意力内部的 dropout 也一并关闭。

close()¶

释放全部子模块

注意

关闭后整个块不可再用；子模块由本块独占。

enum Activation.Kind¶

Activation 支持的激活函数种类

枚举常量共五个：RELU、GELU、SILU、SIGMOID、TANH，与 Tensor 上同名的一元算子一一对应。

枚举只作为 Activation 构造器的分派键，不含字段与方法；取值在 forward 中被 switch 穷举，因此新增常量需要同步修改分派逻辑。

注意

softmax 不在本枚举内；需要 softmax 时直接调用 Tensor.softmax(int)。

参见：jsl.torch.Activation, jsl.torch.Tensor#gelu()
