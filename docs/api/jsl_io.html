模块 jsl.io¶

1 个公开类型

模型持久化使用自描述的 .jsl 容器：固定 24 字节头携带 magic、版本、模型种类编码、载荷长度与 CRC32C。

容器与模型解耦，载荷格式由各模型自己的 write/read 定义，本模块只负责分帧、校验与类型分发。

final class ModelCodec¶

带版本与 CRC32C 校验的 .jsl 模型容器读写器。

容器由 24 字节头与载荷组成，字段依次为 int magic = 0x4A534C4D（"JSLM"）、int version = 2、int kind（ModelKind 编码）、int length（载荷字节数）、long crc32c，随后是 length 字节的模型载荷，均按大端序。

save() 让模型把状态写进内存 ModelWriter，再分配整文件缓冲、填头并循环写出；load() 只读映射整个文件，依次比对 magic、version、长度与文件大小，再在映射区原地计算 CRC32C，通过后把偏移 24 起的零拷贝切片交给按 ModelKind 分发的读取器。

载荷解码完成后要求被完整消费，残留字节视为格式错误。所有失败以未检查异常抛出：结构性问题用 ModelFormatException，I/O 问题包装为 UncheckedIOException。

示例
Matrix features = Matrix.fromRows(new double[][]{
        {0.0, 1.0}, {1.0, 1.5}, {9.0, 8.5}, {8.5, 9.0}});
KMeans model = KMeans.builder().clusters(2).build().fit(features);

Path file = Path.of("kmeans.jsl");
ModelCodec.save(file, model);
KMeans restored = ModelCodec.load(file, KMeans.class);
long bytes = ModelCodec.fileSize(file);

注意

save 会截断已存在的目标文件，且不写临时文件，写入中途失败会留下不完整文件。

注意

load 依赖内存映射，解码期间文件须保持不变；文件被替换或截断时映射区内容不再可信。

注意

版本不匹配直接拒绝，不做向后兼容解析；ModelFormatException 为 RuntimeException。

注意

类为静态工具，无实例（构造器私有），无可变状态，可并发调用。

参见：jsl.core.Persistable, jsl.core.ModelKind, jsl.core.ModelFormatException

方法

save(Path target, Persistable model)static¶

把模型序列化为 .jsl 文件。

先创建初始容量 4096 的 ModelWriter，调用 model.write 得到载荷字节，据此计算 CRC32C，再组装 24 字节头与载荷，以 CREATE、WRITE、TRUNCATE_EXISTING 打开通道循环写出。

target 或 model 为 null 时抛 NullPointerException；载荷长度超过 Integer.MAX_VALUE - 24 时抛 ModelFormatException；打开或写入失败抛 UncheckedIOException。模型的 write 实现自身抛出的异常会原样传播。

注意

载荷完整驻留内存，大模型峰值内存约为文件大小的两倍

注意

校验和在写入前一次算完，写出过程不再重新计算

参数

  • target (Path) – 输出路径，父目录须已存在，已存在文件会被截断

  • model (Persistable) – 待保存的模型，提供 kind() 与 write(ModelWriter)

load(Path source) → Persistablestatic¶

读取并校验 .jsl 文件，返回模型。

映射文件后依次校验：长度不小于 24 字节、magic 匹配、version 为 2、kind 编码可识别、声明长度等于文件大小减 24、CRC32C 与头部记录一致；随后按 ModelKind 分发到对应模型的 read 方法，并要求载荷被完整消费。

任一校验失败抛 ModelFormatException（截断、魔数错误、版本不支持、长度不符、校验和不匹配、载荷有残留字节）；文件打开或映射失败抛 UncheckedIOException。

注意

校验在映射区上原地进行，不复制载荷

注意

返回类型取决于文件内容，需要具体类型时用 load(Path, Class)

参数

  • source (Path) – 输入路径，须为 save 写出的 .jsl 文件

返回

按文件内 kind 构造的模型实例，静态类型为 Persistable

<T extends Persistable> load(Path source, Class<T> type) → Tstatic¶

读取并校验类型后返回模型。

委托 load(Path) 完成全部结构校验与解码，再用 type.isInstance 检查结果；不匹配时抛 ModelFormatException，信息中同时给出期望类型与文件中实际的 ModelKind。

注意

类型不符时载荷已被解码，异常前不会泄漏句柄，但已付出解码开销

参数

  • source (Path) – 输入路径

  • type (Class<T>) – 期望的模型类型，例如 KMeans.class

返回

已转换为 T 的实例，可直接使用具体类型的访问器

peekKind(Path source) → ModelKindstatic¶

只读文件头，返回模型种类。

打开通道读取前 12 字节，校验 magic 与 version 后用第三个 int 调 ModelKind.fromCode。头部截断、魔数或版本不符、编码未知时抛 ModelFormatException；打开或读取失败抛 UncheckedIOException。

不映射载荷，也不校验长度与 CRC32C，因此开销恒定且与文件大小无关。

注意

适合在加载前按种类分派或做工具统计，结果不代表载荷完整

参数

  • source (Path) – 输入路径

返回

文件头 kind 字段对应的 ModelKind 常量

fileSize(Path source) → longstatic¶

返回 .jsl 文件的总字节数。

直接委托 Files.size，不解析头部也不校验内容；文件不存在、不可读或路径指向目录时抛 UncheckedIOException。

注意

载荷大小等于返回值减 24

注意

可对任意文件使用，不要求是 .jsl 容器

参数

  • source (Path) – 输入路径

返回

文件长度（字节），包含 24 字节头

字段

0x4A534C4D()static¶

容器魔数 0x4A534C4D，即 ASCII "JSLM"。

位于文件前 4 字节，save 写入，load 与 peekKind 校验；不匹配时抛 ModelFormatException（"Invalid .jsl magic"）。

注意

注意与 JSLD 数据格式的魔数 0x4A534C44 不同

2()static¶

当前容器版本号，值为 2。

紧随 magic 之后写入。load 与 peekKind 要求完全相等，其他版本一律抛 ModelFormatException（"Unsupported .jsl version"），不尝试降级解析。

注意

版本只描述容器布局，载荷格式由各模型自行定义
