模块 jsl¶

2 个公开类型

jsl 包是 SDK 的入口层。jsl.JSL 持有一个 jsl.nativebridge.NativeContext，把张量工厂、模块构造、优化器、损失函数与计算图句柄收拢到同一个对象上，调用方无需直接接触 JNI 绑定。

该包同时定义统一异常 jsl.JSLRuntimeException，原生 panic、形状校验失败与空参数都会翻译成这一类型，从而在 AutoCloseable 生命周期之上提供一致的失败语义。

类型概览

类型种类说明
JSLclassSDK 统一入口：持有单个原生上下文，集中提供张量、模块、优化器与估计器工厂
JSLRuntimeExceptionclassSDK 统一非受检异常：封装原生 panic、形状拒绝与空参数
final class JSL implements AutoCloseable¶

SDK 统一入口：持有单个原生上下文，集中提供张量、模块、优化器与估计器工厂

门面把「一个原生上下文 + 一套张量工厂」绑定为单一对象。所有由它创建的张量、模块与图句柄都归属同一个 NativeContext，因此反向传播、清空计算图与内存统计天然共享同一份状态，不存在跨上下文混用的问题。

实例内部维护一个 AtomicLong 种子计数器，初值为黄金比例常数 0x9E3779B97F4A7C15。randn、linear、conv2d 每次都从计数器取一个新种子，因此同一实例内的随机初始化序列可复现，且不同层不会拿到相同权重。

经典估计器相关的 fit、predict、crossValidate 是静态方法，仅转发到 jsl.ml.JSL，不读取实例上下文；同一套 API 因此同时覆盖 eager 张量编程与 sklearn 风格的估计器工作流。

示例
try (JSL jsl = JSL.create(4)) {
    Tensor x = jsl.randn(32, 8);
    Tensor y = jsl.randn(32, 1);
    Linear hidden = jsl.linear(8, 16);
    Linear output = jsl.linear(16, 1);
    AdamW optimizer = jsl.adamw(output.parameters(), 1e-3f);
    Tensor loss = output.forward(hidden.forward(x).relu()).mse(y);
    loss.backward();
    optimizer.step();
}

注意

close() 会级联释放该上下文内的全部张量与图，关闭后任何张量操作都会快速失败而不是访问已释放内存。

注意

创建过程需要原生库可用；加载失败时构造函数路径抛出 JSLRuntimeException，而非 UnsatisfiedLinkError。

注意

种子计数器为 AtomicLong，并发调用不会取到重复种子，但调用顺序决定种子分配顺序。

参见：jsl.nativebridge.NativeContext, jsl.torch.Tensor, jsl.torch.Graph, jsl.ml.JSL

方法

create() → JSLstatic¶

以自动线程数创建门面实例

等价于 create(0)：线程提示值 0 交由 Rust 侧按可用核数决定并行度，Java 层不做扩缩容。

注意

返回的实例必须关闭；未关闭时依赖 Cleaner 在回收时释放上下文。

返回

持有新建 NativeContext 的门面实例

抛出

  • JSLRuntimeException – 原生张量运行时不可用，或原生上下文分配返回空指针

create(int threads) → JSLstatic¶

以指定线程提示值创建门面实例

线程数只是传给原生内核的提示值，不做线程池预创建。合法区间为 [0, 256]，其中 0 表示自动。

参数

  • threads (int) – 原生内核并行度提示；0 表示交由 Rust 侧决定，合法区间 [0, 256]

返回

持有新建 NativeContext 的门面实例

抛出

  • IllegalArgumentException – threads 为负数或大于 256

  • JSLRuntimeException – 原生张量运行时不可用，或原生上下文分配返回空指针

context() → NativeContext¶

返回门面持有的原生上下文

用于直接调用上下文级能力，例如 guard()、graphSize() 或 clipGradNorm()。返回的引用与门面共享生命周期，门面关闭后该上下文随之失效。

返回

门面持有的 NativeContext 实例，永不为 null

threads() → int¶

返回创建时传入的线程提示值

返回值原样透传上下文中的线程提示值，不会解析成实际核数；通过 create() 创建时得到 0。

返回

线程提示值，0 表示自动

tensor(float[] data, int... shape) → Tensor¶

由数据构造不追踪梯度的张量

数据按行优先展平后写入原生缓冲区，requires_grad 固定为 false。元素总数必须与 data 长度严格相等，否则由上下文层拒绝。

参数

  • data (float[]) – 初始元素，按行优先解释；不能为 null

  • shape (int...) – 目标形状，各维必须为正；不能为空

返回

归属当前上下文的张量句柄

抛出

  • JSLRuntimeException – data 为 null

  • IllegalArgumentException – data 长度与 shape 元素数不一致、shape 为空、某维非正，或元素总数超过 Integer.MAX_VALUE

parameter(float[] data, int... shape) → Tensor¶

由数据构造可训练张量

与 tensor(float[], int...) 相同的数据校验，但 requires_grad 置为 true，可直接作为优化器的参数列表成员。

参数

  • data (float[]) – 初始元素，按行优先解释；不能为 null

  • shape (int...) – 目标形状，各维必须为正；不能为空

返回

requires_grad 为 true 的张量句柄

抛出

  • JSLRuntimeException – data 为 null

  • IllegalArgumentException – data 长度与 shape 元素数不一致、shape 为空、某维非正，或元素总数超过 Integer.MAX_VALUE

zeros(int... shape) → Tensor¶

创建全零且不追踪梯度的张量

常用于占位缓冲区或需要显式填充的累加器；需要参与训练时应改用 parameter(int...)。

参数

  • shape (int...) – 目标形状，各维必须为正；不能为空

返回

全零张量句柄，requires_grad 为 false

抛出

  • IllegalArgumentException – shape 为空、某维非正，或元素总数超过 Integer.MAX_VALUE

randn(int... shape) → Tensor¶

创建标准正态随机张量

以缩放系数 1.0 从实例种子计数器取种子后调用原生随机初始化，requires_grad 为 false。同一实例中每次调用消耗一个新种子，序列可复现。

参数

  • shape (int...) – 目标形状，各维必须为正；不能为空

返回

标准正态初始化的张量句柄

抛出

  • IllegalArgumentException – shape 为空、某维非正，或元素总数超过 Integer.MAX_VALUE

parameter(int... shape) → Tensor¶

创建全零的可训练张量

该重载是零初始化而非随机初始化：requires_grad 为 true，但所有元素为 0。需要随机初始化的参数应使用 parameter(float[], int...) 或模块构造器。

注意

零初始化会让对称权重在首步得到相同梯度；手工搭建网络时通常改用随机初始化。

参数

  • shape (int...) – 目标形状，各维必须为正；不能为空

返回

requires_grad 为 true 的全零张量句柄

抛出

  • IllegalArgumentException – shape 为空、某维非正，或元素总数超过 Integer.MAX_VALUE

linear(int inputSize, int outputSize) → Linear¶

构造带偏置的全连接层

权重形状为 [inputSize, outputSize]，按 sqrt(6 / (inputSize + outputSize)) 为界的均匀分布初始化；偏置形状为 [1, outputSize] 并置零。种子由实例计数器推进得到。

参数

  • inputSize (int) – 输入特征维，对应前向时最后一维的大小

  • outputSize (int) – 输出特征维，也是偏置的长度

返回

新建的 Linear 模块，requires_grad 参数已就绪

抛出

  • IllegalArgumentException – 形状校验失败时由张量创建路径抛出

conv2d(int inputChannels, int outputChannels, int kernelSize) → Conv2d¶

构造默认步长与填充的二维卷积层

等价于 conv2d(inputChannels, outputChannels, kernelSize, 1, 0)，即方形核、步长 1、无填充。

参数

  • inputChannels (int) – 输入通道数，必须为正

  • outputChannels (int) – 输出通道数，必须为正

  • kernelSize (int) – 方形卷积核边长，同时用于高与宽

返回

新建的 Conv2d 模块

抛出

  • IllegalArgumentException – 任一维参数非正

conv2d(int inputChannels, int outputChannels, int kernelSize, int stride, int padding) → Conv2d¶

构造指定步长与填充的二维卷积层

stride 与 padding 同时作用于高度和宽度两个空间维，因此只支持对称配置。权重形状为 [outputChannels, inputChannels, kernelSize, kernelSize]，按 sqrt(6 / (fanIn + fanOut)) 初始化，偏置形状为 [1, outputChannels, 1, 1] 并置零。

参数

  • inputChannels (int) – 输入通道数，必须为正

  • outputChannels (int) – 输出通道数，必须为正

  • kernelSize (int) – 方形卷积核边长，必须为正

  • stride (int) – 高宽共用步长

  • padding (int) – 高宽共用零填充宽度

返回

新建的 Conv2d 模块

抛出

  • IllegalArgumentException – 通道数或核尺寸非正

<L extends Layout> sequential() → Sequential<L, L>¶

创建空的顺序容器

返回 Sequential.start() 的空容器，布局类型参数在 add 时逐步推导。容器本身不持有上下文，其中模块的张量仍由调用方所属上下文创建。

返回

不含任何模块的顺序容器

<L extends Layout> activation(jsl.nn.Activation activation) → jsl.torch.Activation<L>¶

把激活枚举映射为可组合的激活模块

支持 RELU、GELU、SILU、SIGMOID、TANH 五种。NONE 与 SOFTMAX 没有对应的张量核：NONE 无意义，SOFTMAX 需沿指定维度归一化，应改用 Tensor.softmax(dimension)。

参数

  • activation (jsl.nn.Activation) – 激活函数枚举；不能为 null

返回

对应种类的 Activation 模块

抛出

  • JSLRuntimeException – activation 为 null，或取值为 NONE、SOFTMAX

optimizer(jsl.nn.Optimizer optimizer, List<Tensor> parameters, float learningRate) → jsl.torch.Optimizer¶

按枚举构造优化器实例

三种取值的超参数并不相同：SGD 映射为权重衰减 0 的 SGD；ADAM 映射为 AdamW(0.9, 0.999, 1e-8, 0.0)，即不带解耦权重衰减的 Adam；ADAMW 映射为 AdamW 默认构造，权重衰减 0.01。

注意

ADAM 与 ADAMW 都实例化为 AdamW，区别仅在权重衰减系数；需要无衰减 Adam 时选 ADAM。

参数

  • optimizer (jsl.nn.Optimizer) – 优化算法枚举；不能为 null

  • parameters (List<Tensor>) – 待更新参数列表；不能为 null，元素通常来自模块的 parameters()

  • learningRate (float) – 学习率，原样传给所选优化器

返回

与枚举对应的优化器实例

抛出

  • JSLRuntimeException – optimizer 或 parameters 为 null

adamw(List<Tensor> parameters, float learningRate) → AdamW¶

构造使用默认超参数的 AdamW

使用 AdamW 的两参构造：beta1 = 0.9、beta2 = 0.999、epsilon = 1e-8、weightDecay = 0.01。需要自定义这些系数时应直接调用 AdamW 的六参构造。

参数

  • parameters (List<Tensor>) – 待更新参数列表，元素必须属于同一上下文

  • learningRate (float) – 学习率

返回

AdamW 优化器实例

sgd(List<Tensor> parameters, float learningRate) → SGD¶

构造无权重衰减的随机梯度下降优化器

等价于 SGD(parameters, learningRate, 0.0f)，权重衰减固定为 0；需要 L2 正则时应直接使用 SGD 的三参构造。

参数

  • parameters (List<Tensor>) – 待更新参数列表，元素必须属于同一上下文

  • learningRate (float) – 学习率

返回

SGD 优化器实例

crossEntropy() → CrossEntropyLoss¶

创建交叉熵损失对象

每次调用返回新实例，损失对象本身无状态，可复用于多个前向过程。

返回

新的 CrossEntropyLoss 实例

mse() → MSELoss¶

创建均方误差损失对象

每次调用返回新实例；单次调用也可直接用 Tensor.mse(Tensor) 这一便捷入口。

返回

新的 MSELoss 实例

graph() → Graph¶

包装当前上下文的计算图句柄

返回绑定同一 NativeContext 的新 Graph 包装对象，用于显式查看节点数、清空图或对指定根张量执行反向传播。

返回

绑定当前上下文的 Graph 句柄

clearGraph()¶

清空计算图中记录的所有节点

在两次独立前向之间调用可避免图无限增长；张量本身不受影响，仅丢弃自动微分记录。

抛出

  • IllegalStateException – 上下文已关闭

stats() → long[]¶

读取上下文的内存与图统计

返回长度固定为 3 的数组，依次为存活张量数、存活字节数、计算图节点数，由原生侧一次性填充。

返回

long[3]，含义为 {liveTensors, liveBytes, graphNodes}

抛出

  • IllegalStateException – 上下文已关闭

fit(jsl.ml.JSL.Algorithm algorithm, Matrix features, double[] targets) → Estimatorstatic¶

按算法枚举训练经典估计器

静态转发到 jsl.ml.JSL.fit，使用各估计器的保守默认超参数并按任务类型选择训练路径；无监督算法忽略 targets。该调用不读取实例上下文，可在未创建门面时使用。

参数

  • algorithm (jsl.ml.JSL.Algorithm) – 算法枚举，自带任务类型信息

  • features (Matrix) – 训练特征矩阵，行对应样本

  • targets (double[]) – 训练标签；有监督算法不能为 null，无监督算法可为 null

返回

已完成 fit 的估计器实例

抛出

  • IllegalArgumentException – 有监督算法的 targets 为 null

predict(Estimator model, Matrix features) → double[]static¶

用已训练估计器输出预测值

静态转发到 jsl.ml.JSL.predict，直接调用 model.predict(features)，不做额外的形状或状态校验。

参数

  • model (Estimator) – 已训练好的估计器

  • features (Matrix) – 预测特征矩阵，列数需与训练时一致

返回

每个样本一个预测值，顺序与输入行一致

crossValidate(jsl.ml.JSL.Algorithm algorithm, Matrix features, double[] targets, int folds, jsl.ml.JSL.Metric metric) → doublestatic¶

返回 K 折交叉验证的平均分数

静态转发到 jsl.ml.JSL.crossValidate：按固定随机种子 42 打乱后切分，每折重新 fit 并在测试折上评估，最后对各折分数取算术平均。RMSE 取负值参与平均，因此所有指标都是越大越好。

参数

  • algorithm (jsl.ml.JSL.Algorithm) – 算法枚举，必须是有监督任务

  • features (Matrix) – 特征矩阵

  • targets (double[]) – 标签数组，长度须与特征行数一致

  • folds (int) – 折数，合法区间为 [2, 特征行数]

  • metric (jsl.ml.JSL.Metric) – 评估指标：ACCURACY、MACRO_F1、R2 或 RMSE

返回

各折指标的平均值；RMSE 已取负

抛出

  • IllegalArgumentException – 算法属于无监督任务，或 folds 超出 [2, 特征行数]

close()¶

释放上下文及其全部张量与图

销毁原生上下文并注销 Cleaner 回调。重复调用是幂等的：句柄置零后不再重复销毁，后续张量操作会抛出 IllegalStateException。

注意

关闭会等待正在执行的 JNI 调用结束，因为上下文使用读写锁保护生命周期。

class JSLRuntimeException extends IllegalStateException¶

SDK 统一非受检异常：封装原生 panic、形状拒绝与空参数

原生 Rust panic、JNI 层形状拒绝以及 null 参数都被翻译为该类型，调用方只需捕获一个 SDK 专属异常即可覆盖大多数失败场景。

继承 IllegalStateException 是为了兼容性：已有捕获 JDK 异常的代码无需修改，同时 SDK 用户可以精确区分 JSL 自身的失败与其它状态错误。

requireNonNull 是配套的校验工具，失败时把参数名拼进消息，避免出现无上下文的 NullPointerException。

示例
try (JSL jsl = JSL.create()) {
    jsl.activation(jsl.nn.Activation.NONE);
} catch (JSLRuntimeException failure) {
    System.err.println(failure.getMessage());
}

注意

构造器不校验 message 与 cause，允许两者为 null，与父类行为一致。

注意

形状不匹配等可编程错误仍由 IllegalArgumentException 表达，本类型不替代它。

参见：jsl.JSL, java.lang.IllegalStateException

以消息与原因构造异常

方法

<T> requireNonNull(T value, String name) → Tstatic¶

校验参数非空并原样返回

value 为 null 时抛出消息为 "<name> must not be null" 的异常，否则直接返回该值，便于写成内联表达式。

参数

  • value (T) – 待校验的引用

  • name (String) – 参数名，会被拼进异常消息

返回

非空的 value 本身

抛出

  • JSLRuntimeException – value 为 null
