模块索引

JSL 按包组织 API。每个模块一页，页内按类型分组，类型下依次列出构造器、方法与字段。

模块公开类型职责
jsl2统一门面：一次创建上下文，取张量、模块、优化器，并转发经典模型入口。
jsl.core15基础数据层：行主序矩阵、布局标记、原生经典核、模型容器读写原语。
jsl.data6JSLD 数据管线：流式与内存映射两条读取路径、标准化参数。
jsl.io1模型持久化：.jsl v2 容器（magic + kind + 长度 + CRC32C）。
jsl.ml43经典机器学习：线性模型、近邻、SVM、树、梯度提升、聚类、降维、朴素贝叶斯、指标与切分。
jsl.nn36手写神经网络层：Dense / Conv2D / RNN / LSTM / GRU / 注意力、序列训练与序列化。
jsl.nativebridge8原生桥接专家层：上下文、张量句柄、128 字节指令队列、自动求导入口。
jsl.torch24PyTorch 风格 eager API：动态张量、Module 组合、原生 autograd、优化器与损失。
jsl.concurrent1批量推理编排：虚拟线程 + 信号量限流。

阅读顺序建议

  • 先读 jsl 门面，确认创建上下文与取模块的方式。

  • 张量训练走 jsl.torch；经典模型走 jsl.ml。

  • 需要手写算子或排查生命周期时读 jsl.nativebridge。
